# Odin Library

An intermediate JavaScript project from [The Odin Project](https://www.theodinproject.com/) curriculum: a dynamic, non-persistent library app. This exercise was an opportunity to practice object manipulation.

## Concepts practiced

- Separation of concerns
- Objects, object constructors, prototypes
- Object method implementation
- `this` manipulation
- The `Map` object
- User-defined exceptions with `throw`
- HTML modal dialog boxes (`<dialog>`)
- The `HTMLElement.getBoundingClientRect()` method
- Forms and `FormData`
- Data attributes
- Event listeners, `event.target` manipulation, `event.preventDefault()`
- Random ID generation with `crypto.randomUUID()`
- `for...of` and `for...in` loops

## Lessons learned

Mistakes were made along the way — notes to keep in mind for future projects:

- Project template cleanup should be done at project start and throughout the development phase
- Commit messages should be more readable
- Separation of concerns should be applied more rigorously (different objects in different files, backend/frontend split, accessor/mutator logic clearly separated)
- Branches should be used more often
